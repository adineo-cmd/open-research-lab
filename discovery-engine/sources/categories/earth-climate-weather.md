# earth-climate-weather — 10 sources

| source | what you can do there | agent access | tier | url check |
|---|---|---|---|---|
| [Berkeley Earth](https://berkeleyearth.org/data) | Independent global temperature analysis. | Bulk CSV. | curated | ok |
| [CHELSA](https://chelsa-climate.org) | High-resolution downscaled climate (past+future). | GeoTIFF bulk. | curated | ok |
| [Copernicus CDS](https://cds.climate.copernicus.eu) | ECMWF climate archive: ERA5 reanalysis 1940-present, projections. | cdsapi Python client; free account. | curated | ok |
| [Met Office HadOBS/HadCRUT](https://www.metoffice.gov.uk/hadobs) | UK/international observational climate series. | Text/CSV bulk. | curated | ok |
| [NASA GISTEMP](https://data.giss.nasa.gov/gistemp) | Global surface temperature anomaly series. | CSV bulk. | curated | ok |
| [NOAA Global Historical Climatology Network](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily) | 150k+ weather stations, daily since 1763. | CSV bulk via NCEI access. | curated | ok |
| [NOAA NCEI](https://www.ncei.noaa.gov) | World's largest weather/climate archive: stations, satellites, oceans. | REST + FTP bulk. | curated | ok |
| [Open-Meteo](https://open-meteo.com) | Free weather/reanalysis API with historical + forecast, no key needed. | REST JSON; ideal agent weather primitive. | curated | ok |
| [USGS Water Data](https://waterdata.usgs.gov) | Real-time US streamflow/groundwater. | REST/NWIS web service. | curated | ok |
| [WorldClim](https://www.worldclim.org) | Global climate bioclimatic rasters at 1km. | GeoTIFF bulk. | curated | ok |
