## Validation justifying trust in the model

- Improved solver reproduces all **7/7** previously known values
  (k=2: n=9=23, etc.; k=3: n=9=22; k=4: n=9=21; recorded in
  `ep614-results.md`), and the **k=1** closed form
  `C(n,2) - floor(n^2/4)` at **n=4..12 (9/9)**.
- This session independently re-ran and matched 4 known values:
  n=9 k=2=23, n=9 k=3=22, n=9 k=4=21, n=8 k=2=17 — all OPTIMAL, seconds each.
- k=2 oracle check: this session's n=10 k=2 = 29 and n=11 k=2 = 37 match the
  published Turán reduction `f(n,2) = C(n,2) - ex(n,C4)` with OEIS A006855
  (oracle values 29/37 for n=10/11).

## Rule 0 correction — prior art (see `ep614-prior-art-2026-11-19.md`)

- **k=2 is PRIOR ART, downgraded to independent verification only.** A public
  Jan-2026 note by Quanyu Tang proves `f(n,2) = C(n,2) - ex(n,C4)`, and OEIS
  A006855 tabulates `ex(n,C4)` exactly, giving 29/37/45/54/64 for n=10..14.
  Our k=2 results (29, 37) merely reproduce that oracle — **no novelty claim**.
- Only the **k=3 and k=4 exact values at n=10** (f(10,3)=29, f(10,4)=28) plus
  their witness graphs carry a **conditional novelty claim**: not found in the
  sources checked, but GitHub code search was sign-in blocked and a mirror
  rate-limited, so "first" cannot be certified.

## Honest negatives

1. n=11 k=3 and k=4 remain unresolved (FEASIBLE only). The degree-order
   symmetry-broken model still hardens sharply there: 600 s and 900 s runs at
   6-10 workers left proven lower bounds of 28 and 25 against 37-edge witnesses.
2. The extended frontier reached this session is therefore n=10 for k=3/k=4
   (exact) and n=10 for k=2 (oracle verification); n=11 k=2 exact; no n>=12 data.
3. Witness hints were not applied during the sweep (API mismatch, see above).
   The repo tool's hint path was fixed and re-tested afterwards, but no new
   solve with a hint was run, so it did not change any result in this table.
4. No asymptotic claims — FRS97's general determination is untouched.
