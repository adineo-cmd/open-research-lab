    The data boundary

    • No combined database — every backend uses its own SQLite file inside its own directory.
    • No combined search index — each app builds and ships its own.
    • No shared browser state — only Architecture Archaeologist saves a codebase identifier, and the build checks that no other app does.
    • No API proxy — the portal is static; each frontend calls its own backend on its own port.
    • No backend files in the static site — the build fails if a backend, environment file or database appears in the published output.
