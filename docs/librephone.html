    How the boundary is kept

    Interoperability work stays on the safe side of the line.

    • Blobs are never committed to a repository.
    • Only derived metadata is published: headers, segment tables, hashes, version strings and protocol constants.
    • Every finding ships the script that produced it, so the derivation can be rechecked.
    • Radio work follows the regulatory-safe order: Bluetooth, then WiFi, then GNSS and NFC, with modem last.
